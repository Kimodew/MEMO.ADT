* **Card Surface (พื้นกล่องการ์ด):** `#18181B` (Zinc-900) ถึง `#27272A` (Zinc-800)
* **Text Primary (ตัวหนังสือหลัก):** `#FFFFFF` (White) คมชัด 100%
* **Text Secondary (คำอธิบายรอง):** `#A1A1AA` (Zinc-400) อ่านง่าย สบายตา
* **Border Color (เส้นขอบกล่อง):** `#27272A` ปกติ และใช้สีประจำสาขาแบบจางๆ เมื่อเมาส์ชี้ (Hover)

## 3. แก้ไขจุดบกพร่องเรื่อง Layout จากเว็บหลัก (UI/UX Improvements)
จากข้อสังเกตว่าเว็บหลัก (`adt.mfu.ac.th`) มีบางจุดที่เลย์เอาต์ดูแปลกและใช้งานยาก MEMO.ADT จะปรับแก้ด้วยแนวทางต่อไปนี้:

1. **Clean Grid System:** จัดวางการ์ดผลงานแบบ Responsive Grid ที่มีระยะห่าง (Whitespace) พอดี ไม่อัดแน่นจนลายตา
2. **Clear Information Hierarchy:**
   * หน้าปกรูปภาพเด่นชัด
   * ชื่อผลงานขนาดใหญ่ อ่านออกทันที
   * ป้ายสาขา (CE, DCE, SE, DTBI, MTA, DTT) ใช้สีขอบคมชัด
3. **Intuitive Filtering:** ตัวกรองสาขาและปีการศึกษาอยู่ด้านบนเสมอ คลิกสลับได้รวดเร็วโดยไม่ต้องรีโหลดหน้าเว็บใหม่
4. **Focused Project Modal / Page:** เมื่อคลิกดูผลงาน หน้าจอจะแสดงเฉพาะสิ่งที่ผู้ชมสนใจ (วิดีโอเดโม, รูปภาพ, รายชื่อคนทำ, ลิงก์ทดลองเล่น) โดยไม่มีแบนเนอร์หรือองค์ประกอบที่ไม่จำเป็นมารบกวน
